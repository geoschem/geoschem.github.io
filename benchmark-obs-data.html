Observational data used in GEOS-Chem benchmarks

The GEOS-Chem Support Team benchmarks each new version of GEOS-Chem before it is released. The 1-year full-chemistry benchmarks include comparisons of modeled ozone against observations, both at the surface and as vertical profiles.

The observational data used in those comparisons is listed below and is freely available to the GEOS-Chem community. You can use it to reproduce the benchmark plots yourself, or to evaluate your own GEOS-Chem simulations.

Downloading the data

Both datasets are bundled into a single tarball of approximately 7 MB. Download it with the AWS Command Line Interface:

aws s3 cp s3://geos-chem-1yr-benchmarks/obs_data_for_bmk.tar.gz .

or with wget:

wget https://geos-chem-1yr-benchmarks.s3.amazonaws.com/obs_data_for_bmk.tar.gz

Then extract the tarball:

tar xvzf obs_data_for_bmk.tar.gz

What the tarball contains

Directory Contents Source
obs_data_for_bmk/ebas_sfc_o3_2019 Hourly surface ozone observations for 2019, in NASA Ames format.
  • EBAS, hosted by the Norwegian Institute for Air Research (NILU)
  • Retrieved 15 May 2023
obs_data_for_bmk/sondes_2010-2019 Ozonesonde profiles for 2010–2019 (allozonesondes_2010-2019.csv), plus the locations and elevations of the sonde launch sites (allozonesondes_site_elev.csv).
  • A compilation of global ozonesonde profiles assembled for GEOS-Chem benchmarking

Creating the benchmark plots

The observational comparisons are produced by GCPy, the GEOS-Chem Python toolkit. In outline:

  1. Install GCPy, as described in the Getting Started with GCPy chapter. We recommend installing the geoschem-gcpy package from conda-forge.

  2. Download the 1-year full-chemistry benchmark configuration file, 1yr_fullchem_benchmark.yml.

  3. Edit the configuration file to point to the model output directories on your system, and to the observational data directories that you extracted above. To reduce the run time, select only the plots and tables that you actually need.

  4. Activate your Python environment and run the benchmark driver script: 

    conda activate gcpy_env
python -m gcpy.benchmark.run_benchmark 1yr_fullchem_benchmark.yml
conda deactivate

For the full instructions, including a description of every section of the configuration file and of each plot and table that GCPy can produce, see the Benchmarking chapter of the GCPy documentation. The datasets described above are documented at Observational data used in the benchmarks.
